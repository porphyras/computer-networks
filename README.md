# Computer Networks

Labs from the computer networks course at Novosibirsk State University.
Each task has its own folder; most include a README with run instructions (in Russian).

| Task | What it does | Tech |
|---|---|---|
| [first_task](first_task) | Pinging a list of hosts and collecting latency statistics | Python |
| [Task3](Task3) | Web scraping a Wikipedia category into CSV | Python, Selenium |
| [Task4](Task4) | REST API that stores scraped data in a database | FastAPI, PostgreSQL |
| [Task7](Task7) | Geo-based redirect at the web server level (by client IP ranges) | nginx, Docker |
| [Task9](Task9) | Client/server in a dual-stack IPv4 + IPv6 Docker network, traffic captures | Docker Compose, pcap |
| [Task10](Task10) | DNS lookups for a list of domains, manual vs. scripted results | Python, `dig` / `nslookup` |
